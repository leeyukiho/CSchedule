# Provider Extension Guide

新增学校的唯一执行规程见：

```text
docs/新增学校接入流程.md
```

这份文件只保留英文入口，避免两套扩展规则互相漂移。AI Agent 新增或改造学校时必须先阅读中文规程，并在动手前输出学校接入判型：

```text
学校
是否为全新学校
拟复用 provider
登录层
数据层
是否夹杂一层
推荐接入模式
本次允许标为 enabled
```

全新学校必须先用 Firecrawl 调研学校官网、教务系统入口、登录页、跳转链路和公开可见页面结构。发现 WebVPN、CAS、门户页、前端 SPA、token 签名或 API 网关时，必须明确指出“夹杂一层”，不能按普通教务系统直接照抄。
